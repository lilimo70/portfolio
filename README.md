# Portfolio

転職活動用ポートフォリオサイトの初版です。

企画・情報整理・構成・導線設計・制作・運用改善の実務経験から、現在のWebデザイン・UI設計・フロントエンド制作までを一続きのキャリアとして紹介しています。

## Development

```bash
npm install
npm run dev
```

## Content updates

プロフィール、作品情報、担当範囲、実績数値、Skills、掲載順、連絡先は `src/content/portfolio.js` に集約しています。

## Build

```bash
npm run build
```
